## About The Project
AI Study Assistant is a web-based application that helps students study and revise content from PDF documents using Generative AI.
Users can upload a PDF and interact with its content through a question-answering system. The application uses Retrieval-Augmented Generation (RAG) to retrieve relevant passages from the uploaded document before generating an answer.
In addition to PDF-based question answering, the application can generate a structured summary of the document and create multiple-choice quizzes for revision.
The system also provides the relevant source passages and page numbers used to answer questions, making the generated responses easier to verify.
